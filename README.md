# EL CALENTANO API

Backend TypeScript para **Barber Shop EL CALENTANO** (Metepec, Edomex).

## Stack
- Express + Zod + Prisma + SQLite (dev) / listo para PostgreSQL
- Vitest (motor de disponibilidad, buffers, estados)
- Moneda: **MXN** · TZ: `America/Mexico_City`
- Pago: **solo en local**

## Setup
```bash
npm install
npm run setup
npm run dev
```

API: `http://localhost:4000`

## Scripts
- `npm test` — pruebas unitarias
- `npm run db:seed` — servicios, barberos, horarios
